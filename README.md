
# Практические работы №1–2

Вариант 3 — Проверка характеристик числа.

## Практическая работа №1
Программа определяет:
- Знак числа
- Чётность
- Делимость на 3 и 5
- Является ли число простым
- Количество цифр

## Практическая работа №2
Добавлены возможности:
- Проверка нескольких чисел подряд
- Проверка полного квадрата
- Повторный ввод по ответу да/нет
- Обработка некорректного ввода

## Запуск
python main.py



## Как пользоваться программой

1. Запустите программу.
2. Введите целое число.
3. Программа определит знак числа, чётность,
   делимость на 3 и 5, простоту и количество цифр.
4. Также программа проверит, является ли число
   полным квадратом.
5. Для проверки следующего числа введите "да".
6. Для завершения программы введите "нет".

## Пример работы программы

Введите число: 13

Ваше число: 13
Положительное: да
Чётное: нет
Делится на 3: нет
Делится на 5: нет
Простое: да
Количество цифр: 2
Полный квадрат: нет

Проверить ещё одно число? (да/нет): нет
Программа завершена.
