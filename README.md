# Практические работы №1–3

**Вариант 3 — Проверка характеристик числа**

## Практическая работа №1

Создана программа для анализа целого числа. Программа определяет:
- Знак числа
- Чётность
- Делимость на 3 и 5
- Является ли число простым
- Количество цифр

## Практическая работа №2

Добавлены новые возможности:
- Проверка полного квадрата
- Проверка нескольких чисел подряд
- Повторный ввод по ответу «да/нет»
- Обработка некорректного ввода

## Практическая работа №3

**Тема: Аргументы командной строки и обработка исключений**

Программа дополнена следующими возможностями:

- Работа с аргументами командной строки с помощью модуля `argparse`
- Позиционный аргумент `number` для передачи числа
- Именованные аргументы `--prime`, `--even`, `--square`, `--all`
- Вывод справки с помощью `--help`
- Обработка исключений через `try-except`
- Запись ошибок в `errors.log` с датой, временем, типом и описанием ошибки
- Сохранение предыдущих записей журнала благодаря режиму `append`

## Примеры запуска

Обычный режим:

`python main.py`

Проверка простого числа:

`python main.py 13 --prime`

Проверка чётности:

`python main.py 24 --even`

Проверка полного квадрата:

`python main.py 81 --square`

Несколько проверок:

`python main.py 49 --prime --square`

Полный анализ:

`python main.py 120 --all`

Справка:

`python main.py --help`

## Проверка обработки ошибок

Примеры некорректного ввода:

`python main.py abc --prime`

`python main.py 49 --hello`

`python main.py --prime`

При возникновении ошибок программа выводит сообщение пользователю и записывает информацию в файл `errors.log`, находящийся рядом с `main.py`.

Каждая новая запись добавляется в конец файла без удаления предыдущих записей.

## Используемые модули

`math`, `argparse`, `sys`, `datetime`, `pathlib`.

Все три практические работы выполнены в рамках одного проекта с сохранением предыдущей функциональности.
